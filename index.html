Command Block & Target Selectors
รากฐานของทุกสิ่ง เข้าใจการทำงานของคอมมานด์บล็อกและวิธีเล็งเป้าคอมมานด์ให้ถูกต้อง

⬛ ประเภทคอมมานด์บล็อก

Bedrock Edition มีบล็อก 3 ประเภท แต่ละแบบทำงานต่างกัน:

ประเภทสีการทำงานใช้ทำอะไร
IMPULSEน้ำเงิน/ม่วงรัน ครั้งเดียว เมื่อได้รับสัญญาณ Redstoneเหตุการณ์กดปุ่ม
CHAINเขียวรันต่อจากบล็อกที่ชี้มาหาคำสั่งต่อเนื่อง
REPEATม่วงรันทุกติ๊ก (20 ครั้ง/วินาที) ขณะมีพลังงานตรวจสอบต่อเนื่อง, ตัวนับเวลา
💡รับคอมมานด์บล็อกด้วย /give @s command_block ต้องเปิดโหมด Cheats และอยู่ในโหมด Creative

🎯 Target Selectors (การเล็งเป้า)

Selector กำหนดว่าคอมมานด์จะส่งผลกับ ใคร เสมอขึ้นต้นด้วย @

Selectorเป้าหมายตัวอย่าง
@sตัวผู้รันคอมมานด์เองeffect @s speed 30 2
@pผู้เล่นที่ใกล้ที่สุดtp @p 0 64 0
@aผู้เล่นทุกคนออนไลน์give @a apple 5
@rผู้เล่นสุ่มหนึ่งคนgive @r diamond 1
@eสิ่งมีชีวิตทุกอย่าง (มอนสเตอร์, ไอเทมตก ฯลฯ)kill @e[type=zombie]

🔧 ตัวกรอง Selector [ ]

ตัวกรองความหมายตัวอย่าง
r=10ภายในระยะ 10 บล็อก@a[r=10]
rm=5ไกลกว่า 5 บล็อก@a[rm=5,r=20]
type=zombieประเภทสิ่งมีชีวิต@e[type=zombie]
name=Bossสิ่งมีชีวิตที่มีชื่อนี้@e[name=Boss]
tag=vipมีแท็กนี้@a[tag=vip]
tag=!vipไม่มีแท็กนี้@a[tag=!vip]
scores={kills=10..}คะแนน 10 ขึ้นไป@a[scores={kills=10..}]
scores={lives=..0}คะแนน 0 หรือน้อยกว่า@a[scores={lives=..0}]
c=1จำกัด 1 ผล (Bedrock)@e[type=item,c=1]
hasitem={item=sword}มีไอเทมนี้ในกระเป๋า (Bedrock)@a[hasitem={item=diamond_sword}]
⚠️Bedrock ใช้ c= สำหรับจำกัดจำนวน ไม่ใช่ limit= (อันนั้นคือ Java Edition)

Scoreboard — ตัวแปรสำหรับ Bedrock
Scoreboard คือสิ่งที่ใกล้เคียงตัวแปรมากที่สุดใน Bedrock เก็บตัวเลขต่อผู้เล่น เชี่ยวชาญสิ่งนี้ แล้วคุณสร้างอะไรก็ได้

📦 สร้าง Objective (ตัวแปร)

scoreboard objectives
# สร้างตัวแปรแบบกำหนดเอง (dummy)
scoreboard objectives add coins dummy "§6เหรียญ"

# ติดตามคิลอัตโนมัติ
scoreboard objectives add kills playerKillCount "§cคิล"

# แสดงที่ด้านข้างหน้าจอ
scoreboard objectives setdisplay sidebar kills

# ลบออก
scoreboard objectives remove coins

✏ อ่านและเขียนค่า

scoreboard players
# SET — กำหนดค่าแน่นอน
scoreboard players set @a coins 0

# ADD — เพิ่มค่า
scoreboard players add @p coins 10

# REMOVE — ลดค่า
scoreboard players remove @p coins 5

# TEST — ตรวจสอบช่วง (สำเร็จ/ล้มเหลว สำหรับ conditional chain)
scoreboard players test @p coins 10 *    # อย่างน้อย 10
scoreboard players test @p coins * 50    # ไม่เกิน 50

# RANDOM — เฉพาะ Bedrock! ตั้งค่าสุ่ม
scoreboard players random @p loot 1 100
💡scoreboard players random มีเฉพาะ Bedrock เท่านั้น! Java Edition ไม่มี ใช้สำหรับของรางวัล, เหตุการณ์สุ่ม และความหลากหลายของมินิเกม

🔗 รูปแบบ Conditional Chain

บล็อกที่ 1 ตรวจสอบเงื่อนไข บล็อกที่ 2 ตั้งเป็น Conditional จะรันก็ต่อเมื่อบล็อก 1 สำเร็จ

if-then ด้วย conditional chain
# บล็อก 1 (Impulse/Repeat) — ตรวจสอบ
testfor @a[scores={kills=10..}]

# บล็อก 2 (Chain, CONDITIONAL) — รันก็ต่อเมื่อบล็อก 1 สำเร็จ
title @a title §6§lเกมจบแล้ว!

# บล็อก 3 (Chain, CONDITIONAL)
playsound random.levelup @a

# บล็อก 4 (Chain, UNCONDITIONAL) — รันเสมอ
scoreboard players set @a kills 0

⚡ ระบบ 4: สกิล Dash พร้อม Cooldown
